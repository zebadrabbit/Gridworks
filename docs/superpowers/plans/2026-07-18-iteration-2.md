# Gridworks Iteration 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deposits become wireable nodes, biomass bootstraps power, HUB milestones gate progression, belts/pipes get tiers, splitters/mergers land.

**Architecture:** Static web app, no build step. `src/sim.js` is pure logic (node-testable), `src/game.js` is canvas + DOM. `data/source/satisfactory_data.json` is the immutable source of truth; stats missing from it (biomass burner, milestones, plant rates) are hardcoded constants citing the wiki. Spec: `docs/superpowers/specs/2026-07-18-iteration-2-design.md`.

**Tech Stack:** Vanilla ES modules, canvas 2D, `node tests/test_sim.mjs` (assert-based, no framework).

## Global Constraints

- Never edit `data/source/satisfactory_data.json`.
- No new dependencies, no build step, no framework.
- All sim logic goes in `src/sim.js`; `src/game.js` only renders and handles input.
- Run tests with `./manage.sh test` (= `node tests/test_sim.mjs`). Serve with `./manage.sh start` (port 8889).
- Commit after every task with a `feat:`/`refactor:` message ending in the Claude co-author trailer.
- Save key bumps to `gridworks-save-v2` in Task 2 (old saves discarded, no migration).
- `ponytail:` comments mark deliberate simplifications; keep that convention.

export function removeWire(state, id) {
